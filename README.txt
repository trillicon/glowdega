GLOWDEGA STATIC SITE
====================

A static, no-build website for glowdega.com.

Included:
- index.html — landing/archive homepage
- blog.html — article archive
- book.html — book landing page + preorder/update CTA
- articles/*.html — one independent URL per archived article
- assets/style.css — responsive styling

Design direction:
The site preserves the live Glowdega editorial language: oversized black typography, cream paper background, thin rules, compact uppercase metadata, direct navigation, and a bright acid-green book banner.

Important content note:
The live author site currently says Hadiyah Daché is completing a debut novel and publishing a first short-story/poetry collection, but no official book title or retailer preorder page was publicly available at the time this archive was assembled. The book page therefore does not invent a title, price, ISBN, retailer, or release date.

To publish:
Upload the contents of this folder to any static host. No build step or server runtime is required.
